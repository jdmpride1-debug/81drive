02

手順

A

preload タグを貼る

5分
  1. ブラウザで https://81drive.com/wp-admin/ を開き、WordPress にログインします。
  2. 左側のメニューを一番下までスクロールし、「SWELL設定」をクリックします。 画面上部に「カスタマイザー」「エディター設定」「高速化」などのタブが並んだ画面が出ます
  3. 上部のタブから 「一般」をクリックします。
  4. ページを下にスクロールし、「<head>内に出力するコード」という見出しの大きな入力欄を探します。 見つからない場合は「高度な設定」タブも見てください。それでも無ければ、その画面のスクリーンショットを送ってください
  5. その入力欄をクリックします。すでに何か書いてあれば消さずに、一番下の行に改行して続けてください。
  6. 下の枠の中身をすべてコピーして貼り付けます。（枠の右端が切れている場合は横スクロールできます）
    <link rel="preload" as="image" href="https://81drive.com/wp-content/uploads/2026/09/Hopping-Daikoku-PA%E2%91%A0.jpg" imagesrcset="https://81drive.com/wp-content/uploads/2026/09/Hopping-Daikoku-PA%E2%91%A0-768x432.jpg 768w, https://81drive.com/wp-content/uploads/2026/09/Hopping-Daikoku-PA%E2%91%A0-1024x576.jpg 1024w, https://81drive.com/wp-content/uploads/2026/09/Hopping-Daikoku-PA%E2%91%A0.jpg 1280w" imagesizes="(max-width: 1280px) 100vw, 1280px" fetchpriority="high">
  7. ページの一番下にある「変更を保存」ボタンをクリックします。 「設定を保存しました」と表示されれば A は完了です
B

Cloudflare のキャッシュを削除する

2分
  1. 新しいタブで https://dash.cloudflare.com を開き、ログインします。
  2. サイトの一覧から 81drive.com をクリックします。
  3. 左側のメニューから 「Caching」をクリックします。
  4. その下に開いたメニューの 「Configuration」をクリックします。
  5. ページの上のほうにある 「Purge Everything」ボタンをクリックします。 隣に「Custom Purge」もありますが、そちらではありません
  6. 確認の小窓が出るので、その中の 「Purge Everything」をもう一度クリックします。 「Success」などの表示が出れば完了です
  7. 2分ほど待ちます。すぐ確認すると反映前のことがあります。
C

ちゃんと入ったか自分で確認する

1分
  1. Chrome でシークレットウィンドウを開きます。
    Windows: Ctrl + Shift + N ／ Mac: ⌘ + Shift + N
  2. そのウィンドウで https://81drive.com/ を開きます。
  3. ページの何もないところで右クリックし、「ページのソースを表示」を選びます。
  4. 英数字が並んだ画面が出ます。Ctrl + F（Mac: ⌘ + F）を押して、検索欄に preload と入力します。 ヒット件数が 1件以上になれば成功です。A は正しく反映されています 0件なら、B をもう一度実行して5分待ってから、この C をやり直してください
D

重すぎる画像を差し替える

20分

名称未設定のデザイン.png が 246KBあります。実際は横150pxほどで表示されているのに、1024pxで配信されている状態です。

  1. WordPress管理画面に戻り、左メニューの 「メディア」→「ライブラリ」をクリックします。
  2. 右上の検索欄に 名称未設定 と入力します。
  3. 出てきた画像をクリックします。詳細画面が開きます。
  4. 右下にある 「ファイルをダウンロード」をクリックし、デスクトップなど分かる場所に保存します。
  5. 新しいタブで https://squoosh.app を開きます。（Google が提供する無料ツールで、画像はパソコンの外に出ません）
  6. いま保存した画像を、Squoosh の画面にドラッグ＆ドロップします。画面が左右に分かれます。
  7. 右側のパネルの中にある 「Resize」のチェックボックスをオンにします。
  8. すぐ下に出る 「Width」欄に 300 と入力します。（Height は自動で変わります）
  9. 右側パネル下部の 「Compress」のプルダウンで WebP を選びます。 文字がたくさん入った画像なら、WebP ではなく OxiPNG を選ぶと文字がくっきり残ります
  10. 画面の左下と右下の数字を見比べます。246 kB → 20 kB 前後になっていればOKです。中央の縦線を左右にドラッグして、見た目が変わっていないことも確認してください。
  11. 右下の丸い「↓」ボタンをクリックしてダウンロードします。
  12. WordPress に戻り、「メディア」→「新規追加」をクリックします。
  13. いまダウンロードしたファイルをドラッグ＆ドロップしてアップロードします。
  14. 左メニューの 「固定ページ」をクリックし、トップページ（ホーム）の 「編集」を開きます。
  15. 差し替えたい画像の場所までスクロールし、その画像をクリックして選択します。
  16. 画像の上に出るツールバーの 「置換」をクリックし、「メディアライブラリを開く」を選びます。
  17. さきほどアップロードした画像を選び、「選択」をクリックします。
  18. 画面右上の 「更新」ボタンをクリックします。 「固定ページを更新しました」と出れば D は完了です
  19. B（キャッシュ削除）をもう一度実行します。これを忘れると反映されません。
